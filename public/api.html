REST API Reference

Vita-Gap exposes an open JSON API for automated bioinformatic workflows, pipeline integration, and permalink sharing.

Method Endpoint Description
GET /api/health Liveness check, service health, and software versions.
GET /api/vitamins Catalog of all 9 bacterial vitamins and their pathways.
GET /api/pathways/{code} Specific pathway definition, reactions, and KO options.
GET /api/lookup?q={query}&naming={convention} Symbol / KO / EC lookup and ambiguity inspection.
POST /api/parse Dry-run parsing: token extraction and ambiguity detection.
POST /api/analyze Full pathway analysis answering Q1–Q5 (in-memory).
POST /api/analyses Save analysis report and generate shareable permalink.
GET /api/analyses/{share_token} Retrieve a previously saved analysis report.
DELETE /api/analyses/{share_token} Delete a saved analysis report (requires delete token).
GET /api/export/{share_token}.json Download saved report as JSON attachment.
GET /api/export/{share_token}.csv Download saved report as CSV spreadsheet.
